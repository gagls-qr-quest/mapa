## Ako na ňom pracovať

1. Naklonuj repozitár (GitHub Desktop alebo `git clone https://github.com/gagls-qr-quest/mapa.git`).
2. Otvor priečinok vo VS Code a spusti **Live Server** (pravý klik na `index.html` → Open with Live Server).
3. Uprav kód, ulož, skontroluj v prehliadači (aj v režime mobilu v DevTools, F12).
4. `git add` → `git commit -m "Pridaj …"` → `git push`. O minútu je zmena na GitHub Pages.

Quest, pôdorysy aj spoločná knižnica sa načítavajú z `https://gagls-qr-quest.github.io/`.
Postup hráča, ktorý zapisuje hra, uvidíš len na GitHub Pages (lokálne má prehliadač iné úložisko) –
na testovanie si sprav tlačidlo „Simuluj postup“ (`?debug=1`).
Ako spolu moduly hovoria: [FORMAT.md](https://github.com/gagls-qr-quest/gagls-qr-quest.github.io/blob/main/FORMAT.md).

## Pôdorysy

Ukážkové pôdorysy sú v `questy/ukazka/` spoločného repozitára. Skutočné pôdorysy školy kresli
zjednodušene (miestnosti, chodby, schody, popisy) a zverejni ich až so súhlasom školy.

## Úlohy

Úlohy sú v záložke **Issues**, zoskupené podľa míľnikov. Hotová úloha = funguje na mobile,
beží na GitHub Pages, konzola je bez chýb a issue je zatvorené so screenshotom.
